## ✨ The Vision

**What if a portfolio felt less like browsing a website and more like exploring a universe?**

Deep Space is my personal project to bring that idea to life. Instead of scrolling through a conventional grid of cards, visitors will travel through an interconnected 3D world, discovering projects, technologies, and the story behind the developer.

At the center of the experience: a **massive, cinematic black hole** with a glowing accretion disk, surrounded by stars, particles, and atmospheric lighting.

This project is both a portfolio and a creative playground for learning real-time 3D graphics on the web.

> **Project status:** In development. The sections and interactions below describe the intended experience and will evolve as I build it.

### 🌑 Event Horizon — Landing Scene

A dramatic first impression featuring a black hole, animated accretion disk, deep-space starfield, and elegant typography. Subtle mouse parallax and smooth scroll-driven camera movement will set the tone.

### 🪐 Project Galaxy — Selected Work

Projects will appear as explorable 3D objects. Selecting one will reveal its story, screenshots, technologies, and links without losing the sense of being in a shared universe.

### ✨ Technology Constellation — Skills

An interactive constellation will connect technologies such as TypeScript, Three.js, GSAP, and SCSS. Hovering or selecting a node will reveal more context about how I use it.

### 🛰️ Observation Deck — About Me

A quiet, atmospheric space-station scene will introduce my journey from electrical work into frontend development, with an emphasis on curiosity and building useful things.

### 📡 Transmit a Signal — Contact

A clean contact interface set against a distant galaxy, with a subtle transmission animation and direct links for getting in touch.

## 🛠️ Tech Stack

| Area      | Technology           | Purpose                                               |
| :-------- | :------------------- | :---------------------------------------------------- |
| Logic     | **TypeScript**       | Typed, maintainable application architecture          |
| 3D Engine | **Three.js / WebGL** | Real-time scenes, cameras, materials, and interaction |
| Animation | **GSAP**             | Timeline and scroll-driven camera/DOM transitions     |
| 3D Assets | **Blender**          | Modeling, baking, and optimizing scene assets         |
| Styling   | **SCSS**             | Responsive layouts and DOM UI styling                 |

### Design principles

- **Cinematic, not cluttered:** immersive visuals paired with readable, minimal UI.
- **One connected journey:** GSAP camera transitions link scenes rather than turning them into isolated pages.
- **Performance-aware:** optimized GLTF assets, texture compression, and adjustable visual quality.
- **Accessible by design:** keyboard navigation, reduced-motion support, and non-3D fallbacks.
- **Responsive:** desktop immersion with a usable, touch-friendly mobile experience.

## 💻 Local Development

Clone the repository and install dependencies to run the project locally:

```bash
npm install
npm run dev
```

Then open the local server URL provided in your terminal (usually **http://localhost:5173** or **http://localhost:3000**).

> Setup instructions may change as the project architecture and build tools are finalized.
